# Portfolio Evidence

Proven: the state-transition loop — deterministic extraction into entities,
claims, and evidence; derived confidence with correlation damping and method
ceilings; delta detection with recorded rationale; first-class contradictions
with an evidence-based supersession margin; task-scoped context assembly; action
ranking by expected uncertainty removed per unit effort; an uncertainty metric
with history; graph self-validation; project isolation; SQLite persistence;
read-only API; offline deterministic packaging.

Unproven until live or human work: extraction quality against a labelled corpus,
model-assisted extraction accuracy, whether the ranked actions shorten real
decisions, multi-week team usefulness, production performance, and personal
reconstruction and debugging ownership.
