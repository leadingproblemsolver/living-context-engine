# Cold-User Acceptance Test

Run this with a target user who has not seen the implementation.

1. Give the user only the deployed URL or installation command and README.
2. Ask them to complete the primary workflow using their own realistic input.
3. Do not guide them unless they are irreversibly blocked.
4. Record time to first useful output, errors, misunderstood labels, abandoned steps, and requested exports.
5. Ask: “What would stop you from using this output in your existing workflow?”
6. Fix the highest-friction failure and repeat with another user.

A release is externally usable only when a cold target user can obtain, run, understand, and export the primary result without private explanation.
